페이스북에서 내 게시물 데이터 내려받는 방법
  1. 페이스북 → 설정 및 개인정보 → 설정 → 내 정보에 액세스 → 정보 다운로드 (모바일 앱: 설정 → 개인정보 센터 → 내 정보 다운로드)
  2. 정보 다운로드 요청 만들기를 선택합니다.
  3. 범위: Facebook의 내 활동 → 게시물(Posts) 만 선택하면 용량이 작아 빠릅니다.
  4. 형식은 JSON을 고르세요. (HTML도 읽을 수 있지만 JSON이 훨씬 정확합니다.)
  5. 미디어 화질은 원하는 대로. 중간/높음이면 인쇄 품질이 좋습니다.
  6. 요청 후 준비되면 이메일/알림이 옵니다. 받은 ZIP 파일을 그대로 위에 올리세요. (압축을 풀 필요도, 파일을 고를 필요도 없습니다.)
왜 ZIP을 쓰나요? 페이스북 Graph API로는 본인 타임라인 게시물을 읽으려면 user_posts 권한과 앱 심사가 필요해서, 실제로는 대부분 막혀 있습니다. 내보내기 파일이 사진까지 포함된 가장 완전한 방법입니다.
(실험적) Graph API 액세스 토큰으로 직접 불러오기
대부분의 계정에서는 동작하지 않습니다. 개인 타임라인 글 읽기(user_posts)는 앱 심사 대상이라 일반 토큰으로는 빈 목록이 돌아옵니다. 본인이 만든 앱의 개발자/테스터 계정이거나 페이지(Page) 게시물이라면 동작할 수 있습니다. 사진은 원격 URL이라 시간이 지나면 만료됩니다.
토큰은 이 브라우저 밖으로 나가지 않으며, 페이스북 서버로만 직접 요청합니다. 저장하지 않습니다.
